## Portfolio

### Riverlark Lesson Pipeline
**K-12 edtech · One brief in. A lesson out.**

A seven-stage pipeline that turns one Texas reading standard into a reviewed, text-first video lesson. Claude drafts the passage, automated checks sort every draft into green, yellow or red, and editors make every call. One tested prompt change took a 20-lesson sample run from 8 to 18 green.

Includes: versioned prompts, a validator, two sample runs, an interactive Lesson Studio, a sample video lesson with automated checks, a reviewer guide, onboarding with practice, a rollout plan and a prompt change process.

**[Case study ↗](https://claude.ai/artifact/8cQtYZuDdt3jodLvn8Akp1)** · **[Repository](https://github.com/aptembong/riverlark-lesson-pipeline)**

### Northstar Harbor Ad Review Assistant
**Mortgage · One project. The whole role.**

A Claude skill that pre-screens mortgage marketing for Regulation Z advertising issues and returns PASS, FLAG or HOLD, so loan officers fix problems before an ad reaches Compliance. It never approves an ad; a licensed reviewer makes every decision. Field-tested by a working loan officer on a real flyer.

Includes: the skill and a branded review tool, a quick-start guide, data rules, a hands-on lab, a compliance reviewer guide, an AI champion kit, a service desk article, a leadership briefing, a rollout plan and a usage dashboard.

**[Case study ↗](https://claude.ai/artifact/3eRUWtX9zD8umwhvwBLeP2)** · **[Repository](https://github.com/aptembong/northstar-ad-review-assistant)**
